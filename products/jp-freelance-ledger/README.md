# 個人事業帳簿ローカル

日本国内向けの個人事業者用ローカル帳簿アプリ。日本語・JPY固定で、米国モードや言語切替は持ちません。

- 収入/経費、勘定科目、取引先、証憑種別・参照、摘要
- 月次集計、年次科目集計コア
- CSV出力、SQLiteバックアップ、監査ログ
- ログイン、クラウド、銀行接続、税額計算、電子申告は行わない

国税庁は個人事業者に記帳・帳簿保存を求め、青色申告では正規の簿記による記帳を原則としています。本製品は入力された記録を整理するための道具で、青色申告特別控除や税務上の適否を保証しません。

Store availability: **Japan (JP) only**.
