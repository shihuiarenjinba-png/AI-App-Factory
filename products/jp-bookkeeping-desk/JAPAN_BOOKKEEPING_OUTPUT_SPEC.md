# 日本版 — 帳簿・月次締め・保存の出力仕様

Reviewed: 2026-11-01

## 国税庁一次資料に基づく基本構造

青色申告の標準簡易帳簿:
- 現金出納帳
- 売掛帳
- 買掛帳
- 経費帳
- 固定資産台帳

正規の複式簿記:
取引発生 → 仕訳帳 → 総勘定元帳 / 補助簿 → 試算表 → 貸借対照表 / 損益計算書

国税庁の「記帳のしかた 青色申告編」には、月末に各帳簿の月計を「月別総括集計表（兼決算準備表）」へ移す流れが示されている。

Primary sources:
- https://www.nta.go.jp/taxes/shiraberu/shinkoku/kojin_jigyo/0023005-091_01.pdf
- https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/046.pdf
- https://www.keisan.nta.go.jp/r6yokuaru/aoiroshinkoku/aoiroshinkokuseido/scid1769.html

## 月末に出す「月次帳簿パック」

アプリの月末締めでは以下を1フォルダへ出力する。

1. 月次総括表
   - 現金売上
   - 掛売上
   - その他収入
   - 現金仕入
   - 掛仕入
   - 経費科目別月計
   - 税率区分が必要な場合の区分
   - 未確認・要レビュー件数

2. 取引明細
   - 日付
   - 摘要
   - 相手先
   - 金額
   - 勘定科目
   - 証憑参照
   - review state

3. 売掛・買掛残高一覧
4. 固定資産台帳 / 当月償却
5. 未処理レシート・証憑一覧
6. 現金 / 預金残高チェック
7. 月次レビュー結果
   - 未入力
   - 重複候補
   - personal/mixed-use review
   - asset review
   - tax review

出力形式:
- HTML: 人間確認用、ローカルのみ
- PDF: Windows上でローカルHTMLをEdge headless印刷して作成
- CSV: 再利用・税理士受渡し
- JSON: アプリ内部の再現・監査用

## 保存上の注意

青色申告の帳簿・決算関係書類は原則7年保存が中心。書類によって5年の場合もある。
電子取引で受け取った請求書・領収書等は、紙に印刷するだけでなく電子データを保存する必要がある。
優良な電子帳簿を名乗るには、訂正削除履歴、帳簿相互関連性、検索機能など電子帳簿保存法上の要件がある。製品が要件を独立検証できるまでは「電子帳簿保存法対応」「JIIMA相当」等を表示しない。
